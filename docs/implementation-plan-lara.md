# ラーラ実装計画

## 目的・受入条件

- 4日目終了イベントの会話完了時にラーラを解放する。
- 解放後は日ごとに、ルノヴァ旧市街を除く10箇所から1箇所を現在の居場所として保持する。
- ステージ選択マップでは既存の `LocationMarker` と既存フレームを再利用し、表示中は常時アニメーションする。

## 現状と設計判断

- 日付とラン中の進行状態は `RunState` が所有し、4日目イベント完了は `Main._on_opening_novel_finished()` が確定できる。
- `StageSelectLocationMarker` と location アイコン7フレームは既存実装として残っているため、新しい表示方式は追加しない。
- 通常の `stage_catalog.tres` は現在解放対象の一部だけを持つため、ラーラ候補10箇所は専用 `StageCatalogInfo` Resource に明示し、通常ステージ解放へ影響させない。
- プレイヤーの現在地 (`current_area_stage`) とラーラの居場所は別の状態として保持する。
