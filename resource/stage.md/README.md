## 「最も少ない」の扱い

所持種、装備、胃袋サイズ、開始時刻、成長補正、乱数が指定されていないため、全状況に共通する最小使用数・最短時間・最小被弾は決まらない。本書は現行実装から組み立てた攻略候補であり、全配置・全装備を探索して最適性を証明した解ではない。

比較では次を別々に記録する。

| 指標 | 数え方 |
|---|---|
| 種の使用量 U | 胃袋へ投入してサブスキルを使う回数。装備したままメイン効果だけを使う種は消費0。ただし必要な所持・装備種を別記する |
| 経過時間 T | 戦闘開始から実際に進んだゲーム内分数。巻き戻しで表示時刻を戻しても、実際の経過が短くなったとは扱わない |
| 被弾 D | 敵の通常攻撃・スキル攻撃・吐き戻しによるダメージ。回復したから被弾0とはしない |

まず U=0 の装備・配置案を検討し、時間切れ・回復ループ・致命的な被弾が残る場合だけ、1個の消化でそれを解消できる案と比較する。各ページの「0候補」は**無装備クリア保証ではなく、指定の装備を所持していればサブ消費0を狙う案**。「1候補」も最小1個の証明ではなく、比較する投入案を表す。

使用量に装備数も含めたい場合は、以下の装備セットもコストに加える必要がある。入手前提を満たさない種を、攻略のために自由に追加できるとはしない。

## 共通操作と判断

1. 自動消化を一時停止し、胃袋へ入れる前に回転を決める。胃袋内では回転できない。初期胃袋は横4×縦5、消化ラインは最下段1行。
2. 消化ラインに触れるセル数を増やす。補正なしの通常消化は **1セル50ダメージ、1回30分**。形の長辺を横にするだけで、攻撃される回数を減らせる。
3. 胃袋外の敵は通常攻撃をしない。危険な回復・復活・攻撃役は、倒す準備が整うまで外で待機させる。胃袋内の上段へ置いただけでは攻撃を止められない。
4. 同時投入はラインを分け合える敵だけにする。上に積んで消化できない敵を増やすと、通常攻撃や時間スキルだけを受ける。消化後の落下で隣接・ライン接触が変わることも確認する。
5. 通常消化、種の効果、時間進行時の効果の後に、生き残った敵の通常攻撃が判定される。攻撃前に倒すのが被弾削減の基本。ただし「消化ダメージを受けた時」の反撃、復活、時間スキルは別判定であり、一撃なら常に無傷とは限らない。
6. 「胃袋に隣接」は、参照した実装では盤面外周への接触を数える。内側の空きマスへの隣接とは別。角では同じセルが縦辺・横辺の両方に接する。
7. 手動吐き戻しは通常、最大HPの5%を切り上げた被弾を伴う。単なる位置調整のために繰り返さない。トコン装備時の現行値は50%であり、古い資料の「吐き戻し無傷」は使わない。

## 消費0で働く装備の優先度

装備上限は6個。以下は所持している範囲で選ぶ。敵の回復・無効化・反撃には個別対応が必要。

| 種 | 現行効果・使いどころ |
|---|---|
| ノイバラ | 時間進行時、外周に接するライン内のモノへ500ダメージ。通常の最下段は外周なので、底にいる敵を種消費0で削れる。敵だけでなく花も対象 |
| トケイソウ | メインで消化間隔-20%。他補正なしなら30→24分。回数型の敵スキルの発動回数は減らさない |
| アマリリス | 消化ダメージに胃袋の横×縦×2を加算。初期4×5なら+40で、通常消化の基準は50→90/セル |
| モウセンゴケ | 悪夢が受ける消化ダメージ+50%。一撃で倒せる境目に届くかを優先して判断 |
| マツヨイグサ | 胃袋内のモノが3体以下なら消化ダメージ+50%。花も個数に含むため、余分な投入で条件を崩さない |
| ハス | ライン+1。底に接するセル数を増やし、上段の敵も消化する用途。ライン非接触で有利になる敵には逆効果 |
| ユウガオ | 胃袋の横+1。同時消化の横幅が足りない場合の交換候補 |
| ウイキョウ / ヤドリギ | HPを維持して休憩を避ける保険。被弾そのものを0にはしない |

汎用の比較開始セットは **ノイバラ・トケイソウ・アマリリス・モウセンゴケ・マツヨイグサ・ハス**。6個すべての所持を前提とした案なので、無装備攻略とは明確に区別する。3体条件を保てないならマツヨイグサ、ラインを増やしたくないならハスを、幅拡張や回復へ交換する。

多段攻撃への反撃・増殖がある敵では、通常消化とノイバラの追加攻撃は別の被ダメージイベントになる。一発で倒せる火力にするか、不要な追加攻撃を外す。

## 1個使う価値が大きい場面

| 種 | 消化を検討する条件 |
|---|---|
| オトギリソウ | 現在の最大HP×30を隣接する悪夢それぞれへ与える。最大HP100なら3000。回復役・高攻撃役をまとめて倒せる配置に使う。隣接先ごとに分割しない |
| ノイバラ | 消化時に外周へ接するモノそれぞれへ1500。花への隣接は不要だが、消化した後はその個体のメイン500を失うことも比較する |
| ベラドンナ | 消化時に隣接悪夢の被消化ダメージ+200%。高HPの相手へ長く効かせる用途。メインの確率追加攻撃を確定火力に数えない |
| トケイソウ | 消化後に消化間隔-50%。残りの手数が多いときだけ、花を消化する準備とメインを失う影響を含めて比較 |
| マツヨイグサ | 消化間隔(分)×消化ダメージをライン上へ配分。対象を絞る。短縮装備はこの一撃の威力も下げ得る |
| ゲッカビジン | 表示時刻を2時間戻す。時間切れ救済用であり、実経過時間を短くする手段には数えない |

サブのダメージは最終的に敵側のダメージ処理を通る。無効化や反撃を必ず貫通できるとは仮定しない。花を投入した時点で装備側から外れ、HP・火力・ラインなどのメイン補正が変化する点にも注意する。

## 簡易計算

特殊効果のない敵なら、現在HP H、ライン接触セル c、最終1セル火力 A に対して通常消化回数の目安は `ceil(H / (A×c))`。同じ敵が連続して生存し、通常攻撃だけなら、被弾の目安は `AT×(回数-1)`。

ノイバラ装備中は「通常消化 A×c → 生存していれば時間効果500」という順で考える。無効化、回復、復活、増殖、落下がある場合は上の式だけでは計算できない。

時刻回数型は「何分」ではなく「何回進めたか」、経過時間型は「何分進めたか」が重要。消化間隔を縮めると後者の回復や攻撃を遅らせられる一方、自壊を待つ敵も倒れにくくなる。

最終的な記録欄は `ステージ / 所持・装備 / 開始時刻・HP / 胃袋サイズ / 初期配置・投入順 / U / 実経過T / 表示クリア時刻 / 被弾D / 乱数条件` とする。本書の計算例は実測記録ではない。
